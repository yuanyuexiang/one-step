# 小当家旧站迁移深度审查与补齐清单

审查日期：2026-11-13。对照旧中文站 `http://cn.xiaodangjiacc.com/` 与线上新站 `https://ai-onestep.com/`。本文件记录实际差异、证据和验收标准，不把调研结果当成已实施结果。

## 结论与原迁移口径修正

目前完成的是部署基础、部分产品正文、主图和媒体文件的搬迁，不是旧站完整业务体验的迁移。用户反馈属实：新站损失了相当一部分页面内容、栏目层级、产品展示方式与动态效果。

之前的“320 个图片文件、115 个产品页面、三段视频”只能证明文件和记录存在，不能证明这些素材在正确的页面上完整展示。`200 OK` 只能证明页面可访问，也不能证明内容对等。此前测试未覆盖图库、栏目内容和交互，验收口径不充分。

## 调研方法与证据范围

- 实时请求 46 个旧站 URL，全部返回 200：原中文站清单 44 个，加根入口和一个搜索结果入口；其中包含重复入口，不表示 46 个独立业务页面。
- 浏览器查看旧站首页、折页菜单、企业介绍、商业版图、案例、活动照片、售后、联系、搜索，以及新站首页、公司介绍、地区页、产品页和德语目录。
- 实际操作首页轮播、地区展开、产品缩略图切换、新站产品语言切换与德语目录回退。图片放大入口可见，但这次点击未确认其放大行为；不标为通过。旧表单和客服没有发送测试消息。
- 提取旧页组件 `propJson`、图库结构和页面专用 CSS/JS，与 WordPress 数据和模板对照；没有复制旧 SaaS 脚本到新站。
- 手机、平板及不同浏览器的动态效果尚未完整实测；后台私有资料和客服历史不在采集范围。

证据文件位于 [migration/audit](../migration/audit/)：

| 文件 | 用途 |
|---|---|
| `cn-pages.json` | 46 个 URL 的响应、组件、配置与资源清单 |
| `cn-interactions.json` | 首页 CSS/JS 中的动画与交互证据 |
| `product-gallery-gaps.json` | 18 个中文产品逐项图库差异 |
| `cn-page-map.json` | 旧 URL 到现有新页的对应关系和缺项状态 |
| `newsite-content.json` | 本地 WordPress 公开内容结构及草稿数量快照，不含询盘 |
| `production-pages.json` | 线上选定页面的重定向、语言项、robots 等检查 |

原 HTML/CSS/JS 缓存位于被 Git 忽略的 `migration/raw/audit-cn/`。浏览器客服历史不导入、不存入审查文档。以上是审查时的快照，后续修复需重新验收。

## 产品图库与详情：实测缺项

18 个中文产品里，14 个有多张图库图片。旧源码的图库 `.images-cover .image-item` 与正文富文本是两套结构；之前仅保留一张 featured image 和正文，遗漏图库组件。

逐项对照发现，72 处图库图片引用没有出现在相应新页面的主图或正文中。**这是图片使用位置的缺失，包含跨产品复用，不代表丢失了 72 个独立文件。** 上述缺失引用对应 66 个去重源 URL，全部已有本地文件映射，且已核对文件存在；可以重新关联，无需重建品牌素材。

## 动态效果清单与重建方式

| 编号 | 已取得的旧站证据 | 新站差异 | 重建和验收要求 |
|---|---|---|---|

| I02 | Banner 下方 SVG 四层波浪；CSS `move-forever`，周期 7/10/13/20 秒 | 无波浪动画 | 用独立 CSS/SVG 重建，配合新品牌配色；减少动态偏好下静止，不复制整个旧站样式 |

## 多语言与线上完成度问题

- 已发布产品按语言为简体 18、繁体 18、英语 18、法语 18、意大利语 18、西班牙语 25；德语没有已发布产品。西语多出的记录需核对是否别名或真实新增，不能按顺序强行合并。
- 浏览器确认“折页菜单 → Folding Menu”的同产品关联可用，但英语页正文仍夹有中文及旧站编辑残留；图片内文字也未本地化。该问题不能用七个入口均返回 200 代替语言验收。
- 德语目录的 “English catalogue” 原先链接 `/en/services/`，实际重定向到中文目录；正确目标是已有的英文翻译页 `/en/services-en/`。
- 语言选择器还出现第八项“中文（中国）”，对应空的历史 `zh` 语言；目标范围应保持既定七种语言，不让空配置作为正式入口出现。
- 线上仍显示 `LOCAL DEVELOPMENT PREVIEW` 等开发文字，联系表单也未接入外部通知。需要业务完成度核实后统一上线文案，不能仅删除提示掩盖未完成功能。
- 线上抽查的八个 URL 均含 `noindex, nofollow`：当前还没有开放搜索收录。保持该状态直到内容和迁移验收完成，再有序开启 SEO/GEO；不能把站点能打开说成已能被搜索引擎收录。
- 旧 URL 到新 URL 的映射只是资料清单，不等于已在旧 SaaS 域名上设置 301。旧域名的重定向权限和可操作性需单独核实。

## 原因定位

1. `ops/migration/crawl.py` 对非产品页主要收集 `e_richText`；首页、照片、团队、计数器等是组件内容，因此一些记录的正文只剩公共电话。
2. 产品提取只保存正文和首图，没有独立的图库字段；`import.php` 没有写入图库或产品分类。
3. `site-pages.php` 用通用简介生成关于、地区页面，未读取旧公司页全文；案例只形成待审数据，没有完成前台栏目。
4. 导入过程剥离脚本、样式和表单是合理的清洗，但没有安排等效交互重建，因此动画与业务入口一起消失。
5. 原回归只检查 URL、媒体和表单技术能力，缺少“旧模块—新模块—内容—交互”的对照验收。

## 修复顺序与验收边界

| 批次 | 工作 | 验收标准 |
|---|---|---|
| 1：内容完整性 | 产品图库、四类分类、公司介绍、活动、售后和手册 | 每条旧 URL 均有明确去向；每张图库有归属，原顺序可核对；不能只统计文件数 |
| 2：前台浏览体验 | 首页 5 图轮播、波浪、图库、导航、联系栏、回顶 | 桌面、手机、键盘和减少动态模式实测；视频点击播放、拖动、全屏可用 |
| 3：业务闭环 | 联系人核对、产品来源询盘、通知、售后分流和客服 | 提交一次可在后台追溯来源；通知需收件验证；AI 有知识来源和不能回答时的处理 |
| 4：语言与发布 | 德语内容、其他语校对、空语言清理、旧 URL/SEO 检查 | 切换不丢产品，回退到正确语言；上线文案真实；迁移验收后再确认收录策略 |

每项状态分别记录“源资料已盘点、数据已导入、前台已展示、交互已验证、线上已发布”。本轮不把未实施项标成完成，也不以旧站重复或过时内容为理由静默删除资料。

## 本轮已执行的小范围修复

- 本地源码将德语英文回退改成按语言关系获取真实目录 URL，不再硬编码错误路径。
- 本地语言选择器仅展示既定七种语言，隐藏空的旧 `zh` 入口；没有删除数据库语言或用户资料。
- 增加语言选项数量、回退后的实际语言检查；七种语言导航及 115 个产品页本地检查通过。

以上两项代码修复尚未提交推送，也未发布线上。其余栏目、图库和动态效果是已证实的待补齐任务，本轮以深度审查为交付，不声明已完成重建。
