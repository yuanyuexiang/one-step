## 本次修复

- 重置管理员密码并注销全部登录会话；旧密码、旧会话均失效。新密码仅写入本机忽略目录的私有文件，权限 0600。
- 连续八次失败登录后，按来源 IP 限制十五分钟；被拦截的重试不续延失败计数。
- 后台修改密码时要求至少十六位，拒绝单一字符重复密码。该规则不代替随机密码或双因素认证。
- Apache 阻止本站未使用的 XML-RPC，并阻止上传目录执行 PHP/PHTML/PHAR；插件层同时禁用 XML-RPC 方法。
- 新增登录、用户及角色变更、内容保存、询盘后台访问的审计日志。日志保存于持久化 WordPress 卷的 `wp-content/xdj-private/`，HTTP 禁止访问，文件权限 0600，约五份、每份五 MB 的轮转上限。
- 日志不记录密码、会话令牌、Cookie、请求正文或询盘正文。未新增第三方日志传输。
