## 当前明确不启用的外部能力

用户确认没有模型服务或 SMTP 配置。本次不购买服务、不调用 Beacon 密钥、不安装占用共享服务器资源的本地推理模型。

- 前台资料助手可用；它是公开资料检索，不冒称已接通生成式大模型。
- 询盘保存、来源追溯和后台处理可用；邮件收件邮箱及 SMTP 未配置时不会宣称通知已送达。
- AnythingLLM 接口使用 Docker 内网固定服务地址，API Key 与工作区从服务器运行环境读取。连接后需初始化模型，再做真实回答验收。
- SMTP 接入与后台通知队列已实现，最多尝试五次，开发测试邮箱不发送。配置后需单独验证实际投递。
- 保留当前 `noindex`，由站点负责人在内容核对完成、正式启动 SEO 时通过 WordPress 阅读设置开放收录；不会承诺 GEO 必然被引用。

原图片中的中文和历史资料原文仍有保留，并明确注明来源。外语页面提供本地化界面、说明和操作步骤，不把原图文字声称为已重做翻译。34 条未经核实的独立案例草稿未擅自发布；原公开合作图片和文章已经有前台入口。

## 发布方式与数据安全

项目代码随 GitHub Actions 构建到 WordPress 镜像，图片视频沿用已持久化的 uploads。新增内容和关联通过插件内 `migrate.php` 显式运行，按版本幂等；不在访客请求中自动导入。生产工作流在备份之后运行迁移，不重复导入整个本地数据库，也不覆盖服务器新增询盘。

迁移只更新项目管理的页面和元数据，旧资料可回溯；不会因为默认多语言已建好就再次重建客户数据库。生产发布记录和实际验证结果在本文件末尾补充。
