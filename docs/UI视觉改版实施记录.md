# UI 视觉改版实施记录

日期：2026 年 11 月 14 日。用户已确认按[视觉调研推荐方向](优秀独立站UI视觉设计深度调研.md)执行。

## 已实施内容

采用暖白、深炭色与品牌红的统一视觉体系，保留原红黄 Logo 与已迁移资料。没有新增付费插件、字体下载或大型动画依赖。

- 首页：真实折页菜单与收银设备构成主视觉；四类业务入口；印刷专题；每类两款、共八款精选产品；需求沟通说明；服务地区与历史资料入口。
- 完整目录仍有每语言 18 款产品，分类及产品地址不变。图库、手册、视频和合作展示继续可达。
- 原五张轮播放到首页可展开的资料区，默认手动播放，可切换、暂停或主动播放；资料区关闭时停止定时切换。
- 历史数字仍保留，并明确原始含义、统计日期未提供，不作为当前经营成绩承诺。首页不再以持续波浪动画作为视觉重点。
- 分类页增加分类介绍和真实产品图片；详情页统一图库与信息比例，增加概览、产品资料、咨询的页内导航，并针对四类业务给出不同的询问提示。参数与交付条件仍需核实，没有虚构规格。
- 部分设备详情优先展示现有干净产品图，完整图库与数据库原顺序不作删除或覆盖。
- 手机导航改为可展开菜单，保留语言切换、搜索、咨询；支持 Escape 关闭和焦点返回。禁用 JavaScript 时导航链接仍显示。
- 新增文字覆盖简体、繁体、英语、法语、德语、意大利语、西班牙语。中文标题分行，欧洲语言自然换行。
- 动态效果以图片微移、按钮和边界反馈、用户主动的图库与轮播操作为主；保留减少动态效果支持。

## 主要代码

- `wp-content/themes/xdj-site/design.php`：七语展示文案、精选产品与原始素材选择。
- `wp-content/themes/xdj-site/assets/design.css`：独立的视觉规则，覆盖旧样式并复用原功能。
- 首页、分类、详情及页头模板：信息顺序、布局和导航。
- `assets/site.js`：手机菜单与历史轮播控制。
