- 首页：真实折页菜单与收银设备构成主视觉；四类业务入口；印刷专题；每类两款、共八款精选产品；需求沟通说明；服务地区与历史资料入口。
- 完整目录仍有每语言 18 款产品，分类及产品地址不变。图库、手册、视频和合作展示继续可达。
- 原五张轮播放到首页可展开的资料区，默认手动播放，可切换、暂停或主动播放；资料区关闭时停止定时切换。

- 分类页增加分类介绍和真实产品图片；详情页统一图库与信息比例，增加概览、产品资料、咨询的页内导航，并针对四类业务给出不同的询问提示。参数与交付条件仍需核实，没有虚构规格。

- 手机导航改为可展开菜单，保留语言切换、搜索、咨询；支持 Escape 关闭和焦点返回。禁用 JavaScript 时导航链接仍显示。

- 动态效果以图片微移、按钮和边界反馈、用户主动的图库与轮播操作为主；保留减少动态效果支持。

## 浏览器语言检测（2026-11-27）

按用户确认启用 Polylang 自带浏览器语言检测：无语言 Cookie 时访问根路径 `/`，按 `Accept-Language` 匹配现有七种语言；不匹配时回退 `zh-hans`。已有 `pll_language` Cookie 时优先使用记住的偏好。访问 `/en/` 等明确语言路径时保持该语言，并更新语言 Cookie。不是按 IP 国家定位，也不修改分享链接所指定的语言。

初始化配置和部署迁移均启用 `browser=true`；部署设置在内容版本提前返回之前执行，因此已有生产数据也会更新，避免只影响新安装。使用原有插件和语言 Cookie，没有另建前端跳转脚本。新增只读测试 `tests/browser-language-smoke.py` 并加入 CI，覆盖七语、语言权重、不支持语言回退、Cookie 优先及直接语言路径。

本地使用 8081 预览，全部语言协商测试及 PHP 语法检查通过。已有 Cookie 的访客仍会使用记住的语言；要观察首次访问效果，使用无痕窗口或清除本站语言 Cookie。手动切换仅影响本站偏好，不更改浏览器自身语言。

补充繁体浏览器兼容：`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 匹配繁体，`zh-Hans`、`zh-CN`、`zh-SG` 匹配简体；遵守语言权重和 `q=0` 排除，不覆盖已存在的语言 Cookie。对应组合已纳入本地及 CI 测试。
