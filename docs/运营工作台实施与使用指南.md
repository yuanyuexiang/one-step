# 小当家运营工作台

后台地址：`https://ai-onestep.com/wp-admin/`。保持原有 WordPress 登录、账号权限和 Polylang 编辑流程。

## 日常操作

- 首页显示待处理询盘、已发布产品、产品草稿和已发布页面；产品统计排除旧地址兼容别名，各语言版本分别计数。
- 使用“新增产品”“管理媒体”“处理询盘”“编辑页面”进入原有编辑界面。
- 多语言概览展示七种语言的已发布产品与页面数量，点击语言进入相应产品列表。数量不表示翻译质量已经验收。
- 最近询盘只显示编号、国家、状态和 UTC 时间，完整联系方式仍在受保护的询盘页面中。
- 邮件通知与模型接口按实际配置显示；目前未配置 SMTP 和模型凭据，需直接在后台跟进询盘。

## 界面与权限

采用米白背景、炭黑导航和品牌红按钮，登录页使用原有小当家 Logo。业务菜单使用中文并优先排列。桌面与手机宽度分别调整布局，不替换原生编辑器或多语言控件。

询盘、服务配置和维护入口仅向具有 `manage_options` 权限的账号展示。产品、页面及媒体入口分别检查对应能力；不会给编辑人员增加权限。保留系统通知、站点健康与最近活动，不以美化掩盖异常。

## 验证与维护

```sh
./ops/local.sh cp tests/admin-workbench.php scheduler:/tmp/admin-workbench.php
./ops/local.sh exec -T scheduler wp eval-file /tmp/admin-workbench.php
```

测试只读检查真实统计、管理员展示、受限用户隔离及未登录访问，已加入 GitHub Actions。修改后台样式后重建镜像，并检查首页、产品列表、编辑页、询盘页和登录页。

代码在 `wp-content/plugins/xdj-business/includes/admin.php` 与 `assets/admin.css`，样式限于管理后台和登录页。
