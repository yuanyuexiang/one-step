## 当前结果

- 已盘点六个旧站共 279 个 HTML 页面。
- 115 个产品预览页面、18 组跨语言产品关联；34 条案例保持待审草稿。
- 七种语言入口包含简体、繁体、英、法、德、意、西班牙语。德国旧站实际英文，德语产品翻译仍未完成。
- 已取得 320 个去重本地图片文件，115 个产品页面设置主图，正文不再引用旧图片 CDN。
- 三段去重 MP4 已下载，ffprobe 检查及 ffmpeg 全文件解码通过；新站 HTTP Range 返回 206，支持分段读取。
- 七语视频资料页已建立，首页关联原站介绍视频，视频生成本地封面。
- 对采集 HTML 中链接、src、lazy 及文本文件地址盘点，未发现 PDF、Office 或 ZIP 附件地址；不推断未公开后台文件不存在。

## 下载问题修复

原脚本遗漏 lazy 图片且下载请求缺少来源与 Range 头，不能据此判断资源不可取得。补齐请求后批量下载成功；浏览器归档恢复资源也纳入映射。旧报告中图片 567、视频 403 的阻塞结论已被本次成功结果替代。

## 检查与复现

- tests/media-migration.py：逐个验证本地图片 HTTP 类型、三段视频完整解码与 Range、七语视频页。
- tests/multilingual-smoke.py：七语首页与目录、115 个产品页。
- ops/migration/videos.py：视频下载与 ffprobe 记录。
- video-pages.json：原视频所在页面清单，video-report.json：本地文件与媒体检查数据。
- media-map.json：旧图片地址到本地文件映射；import-report.json：旧产品来源与新 URL。

## 仍需区分的交付事项

本轮已完成采集范围内图片与视频文件的本地迁移和媒体技术验证。网站整体仍有案例审核、德语产品正文及各语校对、旧公司介绍与国家服务信息审核、生产 DNS/旧站重定向、邮件和 AI 客服联调等未完成事项；不将媒体完成表述为全站上线完成。没有发现的附件不算迁移失败。
